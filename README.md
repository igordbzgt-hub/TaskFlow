# TaskFlow

Aplicativo mobile desenvolvido com React Native e Expo para organização e gerenciamento de tarefas do dia a dia.

## Objetivo

O TaskFlow tem como objetivo facilitar a organização da rotina, permitindo cadastrar, visualizar, editar e acompanhar tarefas.

## Funcionalidades

- Cadastro de tarefas.
- Edição de tarefas existentes.
- Definição de prioridade: baixa, média e alta.
- Visualização dos detalhes das tarefas.
- Marcação de tarefas como concluídas.
- Filtro de tarefas: todas, pendentes e concluídas.
- Resumo da quantidade de tarefas pendentes e concluídas.

## Tecnologias utilizadas

- React Native
- Expo SDK 57
- JavaScript
- React Navigation
- StyleSheet

## Estrutura do projeto

- `components/`: componentes reutilizáveis da aplicação.
- `screens/`: telas do aplicativo.
- `App.js`: componente principal e configuração da navegação.

## Telas

1. **Início:** apresenta o resumo e a lista de tarefas.
2. **Nova tarefa:** permite cadastrar ou editar atividades.
3. **Detalhes da tarefa:** apresenta as informações de uma tarefa e permite sua edição.

## Como executar o projeto

1. Instale o Node.js.
2. Clone este repositório:

   `git clone https://github.com/igordbzgt-hub/TaskFlow.git`

3. Entre na pasta:

   `cd TaskFlow`

4. Instale as dependências:

   `npm install`

5. Inicie o Expo:

   `npx expo start`

6. Abra o aplicativo utilizando o Expo Go.
